# code/out/tables

Generated table bodies, as LaTeX fragments. **This directory is generated** and nothing in it should
be edited by hand; each file carries a `generated by …; do not edit` header naming its producer.

A table body is the rows only. The surrounding `table` environment, the caption and the label live
in the paper, which pulls the body in with `\input`.

`code/sync_to_paper.sh` copies every `.tex` here into `tex/tables/`. Edit the producing script,
rerun it, run the sync, rebuild.
